# Smart Home Automation System – DUT Project (2021)

Arduino-based home automation project developed as part of my
DUT in Electrical Engineering in 2021.

## Overview

The project explores the automation and monitoring of a residential
environment using Arduino, ESP8266, sensors, actuators and a mobile
application.

The system includes several functions such as:

- Lighting control
- Temperature and humidity monitoring
- Motion detection
- Gas detection
- Flame detection
- Distance measurement
- Motor control
- Mobile control and monitoring

## Technologies & Components

- Arduino Mega
- ESP8266 / NodeMCU
- DHT22
- LDR
- PIR sensor
- MQ-5 gas sensor
- Flame sensor
- HC-SR04 ultrasonic sensor
- L298N motor driver
- Servo motors
- MIT App Inventor
- ThingSpeak
- Proteus

## System Architecture

The Arduino Mega handles the main sensors and actuators, while
the ESP8266 provides Wi-Fi connectivity for communication with
the monitoring platform and mobile application.

## Project Context

This project was developed in 2021 as part of my DUT studies.
It reflects the technologies, tools and technical approach used
at that time.
